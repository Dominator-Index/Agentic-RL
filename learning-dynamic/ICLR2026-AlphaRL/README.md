## 研究主题

参数更新的低秩与时间演化。研究 RL 权重增量的主导 rank-1 成分及其随训练的演化，并利用早期 checkpoint 外推更新以加速训练。

## 阅读与版本说明

会议为 ICLR2026；本地 PDF 为 arXiv v3。参数空间动力学结论有其模型和任务范围，不代表任意 agentic RL 都满足同样规律。
