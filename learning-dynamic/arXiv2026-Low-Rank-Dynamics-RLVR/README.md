## 研究主题

隐式奖励过拟合与低秩动力学。通过周期性 rank-1 替换研究训练奖励与测试泛化的分离，并分析非 rank-1 成分、奇异谱及奇异向量的演化。

## 阅读与版本说明

与 AlphaRL 的低秩更新视角相关，但强调非 rank-1 成分对域外能力的作用，不能将其概括为所有非 rank-1 更新都无用。目录名称是本地描述性代称，不是论文官方方法缩写。
