## 1. 主要 idea

把 agent 的执行环境、工具、上下文、生命周期、可观测性、验证和治理作为可独立讨论但相互耦合的系统层。

## 2. 关键步骤

1. 用 ETCLOVG 分类法界定 harness 的七层职责。
2. 按组件映射系统、开源项目与研究问题。
3. 讨论运行轨迹如何连接评测、诊断和持续改进。
