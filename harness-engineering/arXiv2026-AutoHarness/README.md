## 1. 主要 idea

让 LLM 根据环境执行反馈写出动作合法性检查器，减少违反规则造成的失败；更自由的设置允许直接合成完整代码策略。

## 2. 关键步骤

1. 在程序树中保存候选 harness。
2. 用 Thompson sampling 选择要继续改进的节点，让 LLM 根据反馈修改程序。
3. 检验动作合法性与任务回报；可从拒绝采样式检查器扩展到纯代码策略。

## 3. 与本专题的关系

展示“改执行约束”也能提高同一模型的效果。它不是仅加一个文本提示；代码策略版本甚至不需要在每一步行动时调用 LLM。同名 GitHub 项目不自动视为这篇 DeepMind 论文的官方代码。

任务／评测：145 个 TextArena 游戏；另在 16 个单人游戏比较代码策略。
