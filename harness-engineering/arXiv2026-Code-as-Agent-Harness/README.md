## 1. 主要 idea

把代码看作推理、动作、环境表示、验证及多 agent 共享状态的运行载体，而不只是模型最终输出的答案。

## 2. 关键步骤

1. 整理代码作为 harness 接口的作用。
2. 比较规划、记忆、反馈和控制等机制。
3. 讨论多 agent 共享程序与产物如何扩展系统能力。

## 3. 与本专题的关系

适合查看系统层面的设计空间。标题在项目页带有说明性副标题，本地目录按 arXiv 标题归档；资源仓库不是独立算法实现。

任务／评测：跨编码、GUI、科学和其他 agent 应用的文献综述。
