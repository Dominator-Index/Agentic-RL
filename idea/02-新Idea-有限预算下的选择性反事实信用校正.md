# 新 idea：有限预算下的选择性反事实信用校正

日期：2026-10-05。暂用描述性名称，不先取算法缩写。分类与近邻见 [信用分配图谱](./01-Credit-Assignment分类图谱与研究空白.md)。

**一句话：不要仅把已有 credit 分得更细；把有限的额外环境交互花在最可能分错信用的步骤上，用真实续跑核验，并校正“只核验疑难步骤”的选择偏差。**

这是候选研究方案，不是已建立新颖性或已验证有效的方法。第一版聚焦可恢复状态的单 agent 工具环境；不同时改分组、进度 reward、multi-agent ratio 和所有训练模块。

## 1. 为什么从这里切入？

便宜信用有不同盲点：

- 终局广播无法区分同一失败轨迹中的正确查询与最后错误。
- 检查进度可能只看见最后写入，看不见必要信息获取。
- 依赖追踪能发现“使用了某条信息”，但不必然知道它是否可替代。
- 诊断可以指出错误，却可能误判或无法定量。
- 真实反事实更直接，但每个步骤都重跑通常太贵。

因此问题不再是“给所有步骤加一种更聪明的分数”，而是：

> **哪些步骤值得花额外成本获取更可靠的信用？只观察这些步骤之后，如何防止训练过度偏向我们主动挑出来的案例？**

这里的“核验”是重新执行替代动作和后续策略，不是让 LLM 再说一次这步重要不重要。

## 2. 已有工作与我们必须承认的重合

[C3 v3](https://arxiv.org/html/2603.06859v3) 已做同上下文替代消息与真实续跑，并分析预算。其附录 A.2 的一个明确前提是续跑计数不依赖采到的动作或结果；A.5 讨论深度怎样分摊预算。因此不能声称首次提出反事实或预算问题。

我们要检验的窄差异是：**由已有轨迹证据主动决定哪些决策点获得核验，同时对这种非均匀选择做显式校正；核验内部先保持固定、非自适应续跑次数。** 是否已被其他主动估计/实验设计方法完整覆盖仍需专项查新。

[VICT](https://arxiv.org/abs/2608.28128)、[IAPO](https://arxiv.org/abs/2608.24588) 的结构信息可用于提示核验位置，但不能把它们的依赖追踪算成我们的创新。[CRAFT](https://arxiv.org/abs/2606.29476) 则是复用已有 sibling 的相邻路线，需区分新增执行与现有样本重用。

经典逆概率校正和最优抽样分配本身也不是新贡献。需要证明这个组合解决 agent 信用获取中的具体问题，并在相同总预算下值得使用。

## 3. 明确目标：我们测的是动作替代后的期望效果

沿用 GiGPO 的轨迹/动作符号 $\tau_i,a_t^{(i)},R_t^{(i)}$，新增的量都直接解释。

第一版限定有限时域、$\gamma=1$、固定旧策略、终局任务奖励 $R_i\in[0,1]$。决策前历史记为 $h_t^{(i)}$，模拟器可恢复该前缀对应的完整环境状态。若 trace 本身不能确定状态，还必须恢复数据库、工具缓存、时间及其他隐藏条件，不能仅恢复聊天文本。

暂省略 $i,t$。把当前动作 $a$ 换成其他动作、之后继续按同一个旧策略运行，定义

$$
Q^{\pi_{\mathrm{old}}}(h,a)
=
\mathbb E[R\mid \text{恢复到 }h,\text{执行 }a,\text{之后用 }\pi_{\mathrm{old}}].
$$

它是标准动作价值，不是新的抽象梯度符号。与旧策略可能采取的其他动作比较，目标信用为

$$
A^{\pi_{\mathrm{old}}}(h,a)
=
Q^{\pi_{\mathrm{old}}}(h,a)
-\mathbb E_{a'\sim\pi_{\mathrm{old}}(\cdot\mid h)}
Q^{\pi_{\mathrm{old}}}(h,a').
$$

这衡量指定续跑策略下的动作差异，不是“宇宙中不可替代的必要性”，也不是固定原后缀不变的字符串删除实验。后续动作必须重新生成，否则换了前缀后的后缀可能根本不可执行。

## 4. 每个被选步骤怎样取得信用标签？

先保留任意便宜初始优势 $A_{i,t}^{\mathrm{base}}$。可用 GRPO、GiGPO 或 HGPO；第一批数学验证用未做标准差归一化的独立 baseline 版本，但核心选择校正恒等式不要求 base 本身无偏。

对一个被选中的步骤：

1. 恢复动作前状态。
2. 固定原动作，独立生成 $M$ 条后续，平均终局奖励，得到 $\widehat Q(h,a)$。
3. 独立采样 $J$ 个替代动作 $a'_j\sim\pi_{\mathrm{old}}(\cdot\mid h)$，每个固定做 $M$ 次后续，得到 $\widehat Q(h,a'_j)$。
4. 构造

$$
\boxed{
\widehat A_{i,t}^{\mathrm{cf}}
=
\widehat Q(h_t^{(i)},a_t^{(i)})
-\frac1J\sum_{j=1}^J\widehat Q(h_t^{(i)},a'_j).
}
$$

cf 表示 counterfactual。$J,M$ 在看到这轮核验结果之前固定；不能采到成功就提前停止，然后仍用普通均值声称相同无偏性质。

替代动作不必与原动作不同：禁止重复会改变 baseline 的动作分布。第一版也不要求 teacher 生成“更好动作”，否则需要另行解释目标和采样权重。

在完整状态恢复、同一冻结策略、独立采样等条件下，反事实估计的期望为上述标准优势。这是经典 Monte Carlo 比较，不作为新定理贡献。

## 5. 新问题：怎么选核验步骤？

### 5.1 不确定性可以引导抽样，但不能直接当 credit

可以使用下面的廉价线索，第一版最多选两种：

- **已有信用分歧：** 不同历史比较或简单价值估计给出不同的符号/排序。
- **检查盲点：** 当前没有验收变化，但动作输出被后续工具参数使用。
- **支持不足：** 相似决策的独立轨迹证据少。
- **核验成本：** 距终局很远的前缀，预计需要更长续跑。

这些是“哪里值得测”的线索，不是正确性标签。依赖边只提示位置，不能直接证明该动作应得正信用。

### 5.2 不用确定性 top-k：保留已知、非零的选择概率

令 $p_{i,t}$ 是步骤被核验的概率，$I_{i,t}\in\{0,1\}$ 表示实际是否选择。两者是新增的采样记号，不是 reward。

第一版先观察已有轨迹，固定所有 $p_{i,t}$，然后独立随机选择；核验产生的新奖励不能回头改变本轮概率。

成本约束为

$$
p_{\min}\le p_{i,t}\le1,\qquad
\sum_{i,t}p_{i,t}\,\mathrm{cost}_{i,t}\le B.
$$

$B$ 是额外核验的期望预算，cost 是预测续跑成本。它不是每次都不超支的硬约束：实际 token 数和抽样数量会波动。若必须硬预算，应采用能记录真实边际纳入概率的抽样设计，不能先 Bernoulli 抽样、超预算后任意截断。

下界要与预算可行性匹配；若预算太少，应降低 floor 或改变设计，不能让一些步骤概率为零后仍声称覆盖所有步骤的校正。

## 6. 核心公式：选择性核验后的残差校正

若只给被选中的步骤换上新 credit，会改变样本构成。由于选择倾向疑难、失败或低进度动作，这种偏差可能是系统性的。

使用

$$
\boxed{
A_{i,t}^{\mathrm{new}}
=
A_{i,t}^{\mathrm{base}}
+
\frac{I_{i,t}}{p_{i,t}}
\left(
\widehat A_{i,t}^{\mathrm{cf}}
-
A_{i,t}^{\mathrm{base}}
\right).
}
\tag{1}
$$

解释：

- 未选中时，保留 base。
- 选中时，使用反事实与 base 的差修正；除以选择概率补偿稀疏核验。
- 不再把高被选概率等同于更高真实训练权重。

固定当前已观测轨迹以及概率，并将潜在核验结果记为随机量；选择随机数与新的续跑随机数独立，则

$$
\mathbb E_{\mathrm{select,replay}}
[A_{i,t}^{\mathrm{new}}\mid\text{已有轨迹}]
=
\mathbb E_{\mathrm{replay}}
[\widehat A_{i,t}^{\mathrm{cf}}\mid\text{已有轨迹}].
\tag{2}
$$

因此概率即使依赖原轨迹的结果、诊断或分歧，也不会仅因“被多选”而改变理想反事实目标。证据指示用于采样，动作价值由真实续跑决定。

这是标准的逆纳入概率残差估计思想；不是新发明。真正需要验证的是在 LLM agent 中成本、方差和信用效果是否达到有用平衡。

### 不要误读成完整 PPO 无偏保证

将式 (1) 用于未裁剪的 on-policy score-function 梯度，并满足真实反事实条件时，可恢复对应原任务策略梯度的期望。实际 PPO 的 min/clip 对 advantage 非线性，不能把式 (2) 穿过 clipping 后继续声称同样结论。

同样，事后截断校正量、删去负 credit、对它再做数据依赖标准差归一化，都可能改变性质。第一版先验证线性更新，再把 PPO 当作需要单独实测的工程版本。

若用混合强度 $\alpha<1$，期望变为 base 与反事实的混合；若 base 有偏，不能声称完全校正。正文核心版本取 $\alpha=1$，并如实面对它的方差代价。

## 7. 核验预算可以怎样分配？

记

$$
v_{i,t}
=
\mathbb E_{\mathrm{replay}}
\left[
(\widehat A_{i,t}^{\mathrm{cf}}-A_{i,t}^{\mathrm{base}})^2
\mid\text{已有轨迹}
\right].
$$

$v$ 是该步骤“可能需要多大信用修正”的二阶量，未知；可用历史核验数据预测，或先用分歧作启发式。它不是直接可见的真实标签。

在独立 Bernoulli 核验、固定内部续跑协议下，最小化各步骤新增抽样方差的可变部分可写为

$$
\min_p \sum_{i,t}\frac{v_{i,t}}{p_{i,t}}
\quad\text{s.t.}\quad
\sum_{i,t}p_{i,t}\mathrm{cost}_{i,t}\le B.
$$

忽略上下界的 KKT 形式为

$$
p_{i,t}\propto
\sqrt{\frac{v_{i,t}}{\mathrm{cost}_{i,t}}},
$$

再按预算及概率上下界截断。平方根分配是经典采样结果，不是算法独创；$v$ 未知时采用估计值也没有 oracle 保证。

这优化的是信用残差抽样方差，不等同完整参数梯度方差。若要优化梯度指标，还需包含动作梯度尺度，增加计算；第一版不再引入难以计算的完整梯度 risk 作为必需组件。

可以用此前随机核验积累的数据预测 $v$，但需保留随机探索以防循环偏见。不能只展示“我们的 priority 比别人合理”，必须与均匀核验、只按成本核验、只按分歧核验比较。

## 8. 一个极小例子：为什么需要校正，而不是只做 hard mining？

两个步骤类型等权，base 都为 0。为方便展示，将信用单位放大 4 倍，理想修正分别为 1 和 3（原奖励尺度下为 0.25 和 0.75）。总期望核验数量为 1。

| 方案 | 选择概率 | 不校正时的总信用期望 | 使用式 (1) 后 |
| --- | --- | ---: | ---: |
| 均匀 | 0.5、0.5 | 2 | 4 |
| 偏向第二步 | 0.25、0.75 | 2.5 | 4 |

不校正时，改变采样规则就改变了整体信用目标。校正后期望一致。

若标签无额外噪声，独立抽样下总信用方差从均匀方案的 10 降到第二种方案的 6。这只是两点构造，说明“如何分配核验预算”可能有意义，不保证任何实际优先级都更好。

已枚举独立 Bernoulli 选择的全部四种结果，核对上述期望和方差：[数值检查结果](./selective_credit_exact_check.json)。这是估计公式的检查，不是训练收益证据。

## 9. All-fail 如何处理？

- 原批全失败，但重放原动作后有不同 continuation：可能发现原动作仍有价值。
- 替代动作续跑找到成功而原动作没有：可获得负信用对照。
- 所有原/替代续跑仍全失败：真实 outcome 的信用估计仍可能全零，不能凭公式制造信息。
- 若另用 ProCredit progress，测量目标就包含了进度；必须与所有对照共用同一评分并另报真实成功率。
- ProGPO、诊断或依赖结构可以提示核验地点，但不自动充当真实反事实标签。

这条路线接受“需要额外环境数据”这一事实，不声称零成本修复 all-fail。

## 10. 最小实验设计

### 10.1 先用可恢复的小环境检验机制

| 环境 | 真正要识别的现象 |
| --- | --- |
| 必须先查 ID 才能写入 | 零即时进度的必要查询 |
| 另有一个无关查询 | 不能把所有探索都奖励 |
| 两个可互相替代的信息源 | 被使用不等于不可替代 |
| 正确前缀 + 随机后续失败 | 把动作质量与坏 continuation 分开 |
| 破坏后修复 | 成功轨迹中的有害动作 |
| 所有分支都难以成功 | 明确无信息边界，不伪造信用 |

用大量独立续跑构造评估参考，它不参与训练，也不参与挑选核验步骤。报告 rank、sign、区间可靠性及策略结果；不能用被训练算法自己的小样本标签证明自己正确。

### 10.2 必须包含的同预算基线

1. 基础 GRPO/GiGPO/HGPO，不加额外核验。
2. 相同额外预算全部用于新的完整 rollout。
3. 均匀选步骤 + 相同反事实协议。
4. 非均匀选择但不校正，隔离选择偏差。
5. 非均匀选择 + 式 (1)，主候选。
6. 在兼容环境中比较 C3 式固定分配与依赖/进度信用路线。

对比必须固定总生成 token、工具调用和训练更新预算，额外 simulator reset、verifier 和可能的优先级模型也要报告。长前缀重放很贵，不能只报被核验步骤比例。

### 10.3 停止推进的条件

- 同预算新增普通 rollout 更好：反事实信用不值成本。
- 均匀核验一样好：结构化选择机制缺少价值。
- 小概率权重导致训练不稳，合理预算下仍无法缓解：校正的方差代价过大。
- 只有 biased clipping 才能工作：改写理论主张，不能继续用无偏性包装。
- 无法准确恢复环境或多 agent 的隐藏状态：不能把结果称为有效执行反事实。
- 新检索发现相同的选择、校正及验证协议：需要进一步收窄或换方向。

## 11. 第一版暂时不做什么，以及为何限制范围

不同时增加新的 process judge、学习 verifier、重新构造历史组或联合 multi-agent clip。已有便宜信用只作初始估计，已有结构只作采样线索。

不把原后缀机械复用为干预结果；不将工具错误恢复、外部世界变化或时序漂移算成动作贡献。

核心主张应是**提高每单位额外环境交互获得的信用质量**，而不是“全程输出最细 credit”。准确恢复状态和额外分支成本，是这条路线最实质的前提。

## 12. 拟议 contribution 与未解决工作

可争取的贡献组合：

1. 明确“信用获取”与“信用分配”的区别，展示稀少验证预算为何需要主动选择。
2. 在决策点层面做有记录概率的非均匀核验，并与真实续跑残差校正结合。
3. 在相同总预算下，证明关键前置步骤的信用质量和最终任务训练同时改善。

目前只完成分类、近邻筛查和构造性数学检查。尚未完成：完整近邻逐式查新、环境快照接口验证、训练实现与预算收益实验。特别是经典主动估计、两阶段采样、控制变量和 C3 的后续工作都必须进一步检查。

**这是一条比“再换一种分组”更直接面向信用正确性的候选方向；是否成立，应由同预算反事实质量与任务训练结果决定。**
